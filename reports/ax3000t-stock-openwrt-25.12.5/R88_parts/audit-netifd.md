## 2. Hot-path overhead
1. Every loop wake-up runs the reaper first: poll_child_output non-blocking read() on stdout+stderr of every running child, try_wait per slot, reap_retired, five pump_* scans (main.rs:4263-4271, 2338-2364; process.rs:135-160): ~6 read + ~6 waitpid syscalls per `interface dump` with udhcpc+odhcp6c alive.
2. interface dump/status: per interface dump_interface_status scans prefixes × prefix_assignments with String clones (main.rs:715-747); clock_gettime per interface/address (interface.rs:80-82, 442-444). Measured -9%/-24% vs C.
3. device status: dump_device clones the whole Device (main.rs:3747-3760); dump_info live ethtool ioctls (device.rs:433-434) as C does (830 vs 898 µs).
4. Link events and every ifup/ifdown: rescan_devices = full RTM_GETLINK dump + read_settings sweep for every device (main.rs:1031-1087), then update_presence one RTM_GETLINK round trip per watched device (main.rs:2865-2884; sys.rs:583-604); ~6 ms CPU per rescan on the AX3000T (main.rs:316-321 comment).
5. Netlink command path allocates a fresh 32-64 KiB Vec per request/dump_one (netlink.rs:282, 355).
Leaks: none found (claims/parents/claimed_* removed on release main.rs:943-968; protos entries on reload/remove; RETIRED drained each loop; hotplug queue ≤1 per interface). Config.errors never populated → "refuse reload" branch main.rs:407-415 dead (contract F14).
