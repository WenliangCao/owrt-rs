# v0.2.2 — 十组件安全边界与编译检查

发布说明草稿；短回归通过，同一镜像已刷写一次，物理健康及资源观察正在收尾，尚未发布 GitHub Release。

本版统一清理 dnsmasq、procd、ubusd、netifd、rpcd、logd、httpd、fw4、uci、reload-config
以及共用 ubus 库。业务 src 中 unsafe block 从 545 降到 0，业务 crate 以
`#![forbid(unsafe_code)]` 强制守住边界；路由器目标平台编译警告清零，CI 遇到编译警告即失败。
必要的系统 ABI、信号、进程和 FD 操作留在受审查的 platform 封装内；不是整个依赖图零 unsafe。
唯一新增第三方直接依赖为固定 rustix 1.1.5。

OpenWrt 25.12.5、AX3000T、十组件原生路径和配置迁移协议保持一致。
DNS 保留 K 的快路径与 fork 行为，重新训练固定 PGO。没有启用 AD/CD 或 EDNS 的备用快路径。
统一构建必须从源码重现验收过的十个 ELF；CPU/延迟结论以同机隔离对照为准。

验收发现并拒绝了一次 procd 迁移回归：waitpid(None) 只等待同进程组，遗漏 inittab 的
独立会话。修复改用等待任意子进程的接口；原 R71/R83 实测恢复为 1→2 和 11 次，
与 C 相同，并增加独立会话回收回归。旧候选未部署，失败记录保留。
