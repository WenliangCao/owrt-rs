# R124 大事件后容量保留：预定内存检查

只有通过 R124 功能、FD 和指令筛查后才采实机数据；工具实现可提前独立完成。
只比较精确 C 与最终保留的 R124 ELF，不用本组推导 R124/R123 增量。
C 也复用全局 blob_buf，不能预设 C 零保留。数据均来自受保护临时命名空间，生产保持 C。

新增独立的原版 libubus C 内存 helper，不修改或重建现有 CPU helper。
两个连接分别发送和接收固定事件；先验证一次小事件、完成 listener 的 LOOKUP/STATUS 屏障，输出 READY 并保持连接。
控制管道收到 SEND 才发大事件；确认发送成功、事件名称、每个载荷字节和恰好一次接收。
回调及事件读取函数返回后再完成 listener 的不存在对象 LOOKUP/STATUS 屏障，才输出 DELIVERED。
发送 STATUS 本身不能当作接收排空。CLOSE 后移除 handler、关闭两连接；采样器还必须确认 daemon FD 回到基线。
每步有超时，错误保留证据；启动时固定 argv0=/sbin/ubusd 和 daemon CPU1，helper CPU0。

尺寸指 bytes 字段有效字节数：32768、262144、786432；额外记录完整编码长度。
每个尺寸使用全新 daemon。四个窗口、十二个病例固定如下，不追加至结果稳定：

| 窗口 | 实现 | 尺寸顺序 KiB |
|---|---|---|
| 1 | C | 32、256、768 |
| 2 | R124 | 32、256、768 |
| 3 | R124 | 768、256、32 |
| 4 | C | 768、256、32 |

每病例采空载、两连接及小事件预热后、大事件完整验证后保持连接、完全断连四阶段。
后三阶段在完成握手或 FD 回落后固定等待 1 秒和累计约 5 秒采样，不看数值后延长。
保留同一快照的 VmRSS/RssAnon/VmData、前后进程身份、FD、argv0、ELF/库/工具哈希。
PSS 不可读就记 NA；RSS 不是 allocator 容量或峰值。
报告每轮绝对 KiB、held−connected_baseline、disconnected−empty_baseline，以及候选/C 差值，不用两轮做统计胜出声明。
外层复用 r95_device_smoke 的安装禁止、120 秒 guard、清理与健康身份校验；不修改生产配置或服务。
工具、产物与 JSON 排程在采样前冻结；任何阶段失败停止并保留，不覆盖失败目录。
