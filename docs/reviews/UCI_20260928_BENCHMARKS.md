# UCI 四侧实机详细表

正式 canonical ELF；每侧四轮，随机完整块交错；每负载每轮 200 次独立操作，5 次预热。表格为逐轮统计的中位数 [最小, 最大]。差值为候选减基线，括号内为百分比；方向逐轮配对，箭头只表示数值变化。吞吐以 ops/s 计，其他时延/CPU 以 µs 计。

command CPU 来自 getrusage(RUSAGE_CHILDREN)，包括被回收命令树；set_commit_get 包含 shell 和三个 CLI。caller CPU 是校验/启动/采样工具本身，另列。计数编码 1 µs、进程时钟报告 1 ns，均不等于实际精度。p99 仅为每轮 200 样本尾部次序统计，不作显著性结论。
