同样中位约 −3.60%，但区间跨零。其 daemon CPU 两规模分别 −3.52%/−3.99%，各十窗口均下降。
匹配事件四单元的耗时中位仍高于 C 2.20%～3.18%，其中三项区间跨零，不能称所有匹配场景都可靠更慢。
这仍不足以宣布整体性能目标完成。rank interval 对 24 项作 Bonferroni 校正并假设窗口比值独立同分布；
未由本系列证明这些假设或 A/A 分辨率。±1% 只是工程平手带，不是统计等效性检验。
