# R99：先校准注册 CPU 计量，再验证回复复用

用户转来的评议指出两个值得执行的方向：ADD/REMOVE 回复仍有重复分配，微小 CPU 变化需要
同指标的计量校准。采纳这两点，继续 ubusd 目标；不把注册低频当作全面胜 C 的豁免。

## 对诊断的核实

- 回复确实仍新建 `BlobBuf`，再 `to_vec`，可以改用现成 scratch 和借用发送。
  不过 `Client::send` 接收已有 Vec，排队时转移所有权，并非必然再复制；
  BlobBuf 还会增长，不能未经插桩把调用次数精确写成每回复两次 malloc。
- ADD/REMOVE 的 DATA 只含 OBJID 和可选 OBJTYPE，blob 分别 12/20 字节，**不随方法数变大**。
  64 个方法增加的是请求、校验和注册构造成本。固定回复成本可能解释一部分比例变化，
  但不能仅凭两条 lane 证明它是全部差距或唯一杠杆。
- R98 按需事件编码已触及另一项固定成本，不是对象存储优化；无监听者时它使注册 CPU 明显下降。
- R97 暂缓值来自八个独立配对，而非四个：单方法自身 CPU 变化依次为
  +1.394%、+3.090%、+9.766%、+0.703%、+0.238%、+1.599%、+1.649%、+2.160%。
  p99 的 −1.02%～+41.23% 不等于这个 CPU 指标的采样噪声。
  八次同向不证明因果/全面退步，也不能直接称为随机正负各半。
- R96 以来实际使用的进程 CPU 时钟已在循环外采样。新工作解决迁核、运行长度、
  每请求延迟采集扰动和 A/A 分辨能力，不能声称之前只有粗 tick 计数。

此前 1% 是保守的继续调查门，不是统计显著性门。今后微小回退的调查先用经过 A/A 校准的
同指标实验；所有先前反向结果仍保存，不因新的解释删除。

## 新仪器与实验边界

`register-cpu` 保留实际 Unix socket、ADD/REMOVE、返回状态及初末完整性校验，串行长循环，
去掉每请求延迟采集和 latency 数组，循环边界直接读取 daemon/client CPU 时钟。
完整 proc 快照在该区间外，仍记录 PID 创建时间、CPU 分辨率、上下文切换、内存和频率观察。
它是实际协议的 CPU 诊断；不是绕过 socket 的纯算法基准，也不能代替延迟/并发/失败路径验收。

使用 `exec-cpu` 仅将隔离候选 daemon 固定 CPU 1、测试 client 固定 CPU 0，验证实际 affinity。
Linux affinity 是线程属性且跨 exec 保留，见
[Linux sched_setaffinity 文档](https://man7.org/linux/man-pages/man2/sched_setaffinity.2.html)；
进程 CPU 时钟包括该进程各线程 CPU，而非等待时间，见
[clock_gettime 文档](https://man7.org/linux/man-pages/man3/clock_gettime.3.html)。
不修改生产进程、IRQ、governor 或系统启动配置。不预先承诺固定核心就能把噪声压到 1% 以下。

先用字节相同的基线 A/A 校准，再冻结候选确认。报告同一指标的运行散布、配对变化和区间；
若不能分辨预定的小效应，结论是证据不足，不按变化正负淘汰或宣称等价。
百万次请求不等于百万个独立统计样本；按独立运行配对推断。受每次物理窗口的安全时限约束，
优先增加独立的较长窗口，不能为凑整百万次突破守护限制。

## 回复候选

基于接受运行时 `5a19517` 单独构造，未叠加尚在验证的 R98：

- ADD/REMOVE DATA 用 `scratch.reset()` 和 `send_scratch`，保留 monitor→发送边界；
- Publish ACL 只借用 uid/gid/额外组，消除为了只读检查而克隆用户名、组名和额外组；
- 队列仍拥有未发送的字节；REMOVE 的 DATA→删除/通知→STATUS 顺序不变。

代码见 [候选补丁](r99-registration-reuse.patch)。构建机 30 条单测通过，新测试故意积压
64 个注册/删除周期，核对所有 DATA/STATUS 内容、请求序号及监控镜像，确保 scratch 后续覆盖
不会破坏排队内容。早期新增测试误用了普通消息属性策略解析 monitor SEND-u8，已修正测试解析器；
这不是运行时行为故障。功能实机和性能确认尚未完成，候选没有合入或部署。

新计量客户端四条构建机单测与 clippy 通过，包括独立线程 affinity、进程时钟线程/睡眠/退出语义。
实机计量验证和 A/A 尚未完成。R94 的十条探索 lane 也未覆盖这里的注册、完整内存和所有尾指标，
不能据此认定全面目标已完成。路由器生产保持 C，每个隔离窗口必须通过健康和清理检查。
