## 仍未解决

- 512 B 单客户端静态 CPU R89 82→source05 89 µs（+8.54%），四轮范围 79–84 对 86–93，未重叠；平均延迟 +3.76%。四客户端 CPU 110.12→116.57 µs（+5.86%）。尚未归因。
- JSON-RPC 四客户端 HTTPD CPU C 467.76、R89/source05 均 484.13 µs，source05 对 C +3.50%；四轮范围重叠。source05 原版依赖 CPU 中位数 399.31，C 为 472.22 µs；低依赖开销不能冒充 HTTPD 自身 CPU 胜出。
- 并发 CGI 平均延迟比 R89 高 4.14%，范围有重叠；CPU 中位数 +0.35%。多数其他静态 CPU 与 R89 的差值较小，见原始范围。
- 停放后 60/80 ms 成本仍未追上 C；本矩阵不改变 [既有间隔结论](R93_HTTP_DEVICE_BASELINE.md)。
