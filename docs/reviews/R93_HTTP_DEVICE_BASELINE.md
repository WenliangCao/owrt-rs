## 口径与限制

- 16 KiB 静态文件、4 客户端；gap 0 每样本 10,000 次，其他每样本 1,000 次。gap 是应用请求间隔，不是 Wi-Fi RTT。
- 主表为 HTTPD 自身被测请求区间 CPU；原始资料另保留三 daemon 同一 outer 区间，含每客户端一个预热。不能相加。
- 2 ms 线程观察器在不同实现上的成本可能不同；这是诊断结果，未替代冻结客户端的 74 项性能矩阵或整机冷启动窗口。
- SDK 发布链接/裁剪配方一致，但候选由 AArch64 GNU Rust host 构建，正式 R89 来自 x86_64 CI；不宣称相同字节布局或 canonical 发布。
- 资源采样在结束、1 秒、2 秒，包含 RSS/匿名页/文件页/fd/thread；不覆盖 200 ms 内存门，也不是 PSS。
- 当前性能源码仍为修复版；worker cache、logd span 和 ubusd 迭代优化尚未合入。
