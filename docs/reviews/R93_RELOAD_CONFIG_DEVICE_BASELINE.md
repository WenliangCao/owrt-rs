## 验证与范围

- 每侧每轮 500 次计时、5 次预热；全部命令成功、stdout 字节精确校验为空。
- 计时前先建立各自 config.md5，计时前后均与原版输出逐字节相同；两侧调用原版 UCI，使用私有 /var/run。
- CPU 为命令与后代累计量；后代可能并行，累计 CPU 可高于单次墙钟，不能把它当单线程 daemon CPU。
- 12 样本完整原始集合与 SHA 核验通过，共 168 文件；设备配置、boot、生产身份与客户端健康门通过，生产仍为 R92。
- 本组只覆盖 unchanged-config，不覆盖改动传播、事件风暴或整栈冷启动；这些不能用当前成绩替代。
- source05 为同 SDK recipe 的 Oracle 诊断构建，非 canonical CI 发布。
