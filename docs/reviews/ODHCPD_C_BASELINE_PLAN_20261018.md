# odhcpd 隔离 C 基线计划

成本模型：首主动 RA 约为服务初始化加 C 固定 1 秒 timer；RS 与 DHCPv6 首回复
主要是一次收包、协议处理和发包；常驻内存主要为映射代码页、配置和租约。
本轮先测精确 C 的真实包、状态及生命周期边界，不筛选算法或优化候选。
预测首主动 RA 约 1 秒，RS/DHCPv6 不等待该 timer；单纯 Renew 不重复触发
hosts 更新；GUA /64 无下游 PD 容量，ULA /60 可以分配 /62；C 的运行时 ubus
断开不会自行重连。预测不符时先检查仪器和源码，不抹平输出。

Oracle 独立 mount/net/PID namespace，复制精确现役 rootfs 到新输出目录。
所有配置、ubusd、netifd provider、状态文件和网络设备只在该隔离空间；客户端
在第二个 netns，以真实 veth 交换 IPv6/ICMPv6/UDP 包。不访问物理路由器，
不改原始证据。父输出目录可为 0700，内部运行 umask 022，允许 ubusd uid 81
遍历私有 /tmp/run。精确 C SHA256 为
`53e534a12d412b1f138ab95d15431bc109bbb356dbfadfb8625397d585d2be82`。

固定一个功能场景序列：启动/首主动 RA/RS、NA 与 PD 四步及续期、时区 ORO、
租约和 trigger、旧前缀替换与默认路由删除、daemon/ubus/provider 生命周期。
每个运行使用全新目录；不热循环，不做 PGO，不设微秒门槛。记录原始包 hex、
单调时钟发送/接收值和分辨率、内核路由、ubus/文件、相同阶段 RSS/RssAnon。
首包时间只作后续同夹具 C/Rust 比较输入；单次 Oracle 数据不能证明物理路由器
性能门已通过。后续验收只归一化非语义事务 ID/绝对时间，不能消掉地址、状态、
选项或寿命差异。

一次完整序列预计 1–2 分钟；每次请求超时有界。任一隔离、身份或协议前置条件
失败即停止并保留原件；允许定位后修仪器，再只运行受影响阶段，不以重跑选好数。
C 已知产品边界单列记录，不作为仪器失败。本轮交付一个可重放工具、一份 C 结果，
以及替换 ELF 后复用的候选接口；扩展合同中的其他边界沿用同一工具，不另建框架。
