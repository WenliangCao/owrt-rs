# v0.3.0 后仓库整理

2026-10-18。README、8 个 GitHub Release 文案及已退役工作目录完成整理。
没有修改产品代码、固件附件或路由器，没有执行新的性能测量。

README 改为按柏林日期倒序的项目时间线，记录组件接管、优化和发布。
日期取自 Git 历史及已提交报告；v0.2.3 的发布时间换算为柏林日期是 10 月 18 日，
没有直接采用报告文件名中的 10 月 17 日。项目目标改为逐步用 Rust 替换
OpenWrt 中能够替换的部分。

八个 Release 的标题和正文统一为中文，副本保存在 [docs/releases](../releases/)。
七个固件版本都使用同样的十一组件、六列表格；PGO 输入发布使用同一表头，
明确它仅包含 dnsmasq 构建输入。表中只使用可对应本版程序的现有测量，
未测项目写“未测”，不把 Rust 版本间比较填成 C 对照；原报告里的性能退步和
诊断限制保留。标题及正文不再列 SHA 或构建身份。

更新后逐条回读，Release 标签、发布时间、草稿/预发布状态、全部附件身份及
v0.3.0 的 Latest 状态均不变。操作时没有开放的草稿 PR，因此没有改动 PR 描述。

Oracle 上各互不重叠删除路径原占用合计 **11,525,730,304 字节（约 10.73 GiB）**。
首批删除前至最终检查，文件系统实际已用空间减少 11,525,660,672 字节，
与目录占用相差 69,632 字节；没有将并行批次的 df 差值相加。
每批删除前检查进程 cwd/root/exe、打开文件、内存映射及挂载命名空间。
没有停止进程、卸载挂载点或操作无关服务。

73 个原来只在 Oracle 上的源码和测试工具保留于

设备配置、密钥、镜像副本、抓包及原始运行状态不入 Git。

Oracle 的旧 dirty 主仓库、精确上游基线、原厂镜像/SDK 基础设施、当前发货 rootfs、
