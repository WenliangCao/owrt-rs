# R124：大事件后的实机驻留内存

四个预定窗口、十二次全新 daemon、84 个快照已完成，并经独立原始数据复算。
[冻结计划 v2](r124-memory-plan-v2.json)只修复第一组采集器不支持小数 sleep 的问题；
[首窗失败记录](r124-memory-failed-01.json)保留，0 个快照，不计入正式结果。
全部测试位于临时命名空间；最终生产仍为相同 PID/ELF/boot 的 C，临时目录已清理。

每次先处理 16-byte 小事件，再处理一个大事件，验证完整载荷和 listener 的 LOOKUP/STATUS 屏障；
保持连接及完全断连后各在 1/5 秒采样。36 对内存快照的 1/5 秒值均相同，
实测等待为 1.00–1.01 / 5.04–5.07 秒。以下是两反序块的全部取值范围，单位 KiB。

| 有效载荷 | C/R124 各自增加的 RssAnon、VmData、VmRSS | C 保持连接/断连 RssAnon | R124 保持连接/断连 RssAnon | C/R124 保持连接/断连 VmData |
|---|---:|---:|---:|---:|
| 32 KiB | 都 +36 | 108 | 80 | 80 / 84 |
| 256 KiB | 都 +260 | 328–332 | 300 | 304 / 308 |
| 768 KiB | 都 +772 | 844 | 816 | 816 / 820 |

增加值同时指 held−connected 与 disconnected−empty，两种口径下 R124−C 的增量差均为 0。
空载/小事件后 RssAnon 为 C 68–72、R124 40–44；VmData 为 C 44、R124 48。
各配对绝对 RssAnon，R124 少 28 KiB，第二块 256 KiB 病例少 32 KiB；VmData 均多 4 KiB。
因此，本组没有显示 R124 scratch 复用引入了高于 C 的额外驻留增量。
它也没有实现“所有内存字段都低于 C”，4 KiB VmData 差仍需明示。

PSS 全部不可读，保留 NA。VmRSS 含不同静态/动态链接与共享页，不能把总 RSS 差当唯一开销评分。
本组不是峰值、长时间空闲、连续递增消息、慢读排队、内核 socket 内存或完整组件内存测量；
仅两个反序块，不给置信区间或总体胜出声明。没有直接 R124/R123 对照，不推导增量优化收益。

候选 ELF `42435a31e2917186fb353e2c70143f4b3f6d82ec3dd53265bf6d826897b69926`。
[完整派生结果](r124-event-memory-results.json)保留每窗/病例/时点、真实 elapsed、差值、
工具及六库身份、800 个 raw 文件摘要、独立审计和最终路由器健康证据索引。
本结果补齐 R124 的大事件驻留检查，不改变八对象事件耗时仍约慢 2% 的性能结论，尚未最终接受。
