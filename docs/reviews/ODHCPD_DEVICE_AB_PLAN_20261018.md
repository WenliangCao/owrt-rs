# v0.3.0 odhcpd：唯一一轮路由器隔离 A/B

用户新增发布门：审计修复后的最终 Rust ELF 与精确 C 在路由器隔离比较。任何
指定指标 Rust 超过预先固定的噪声即停止汇报，不优化、不补样、不刷机。当前
生产仍为 v0.2.3 与 C odhcpd。本计划在设备采样前冻结，取代旧候选的性能决定；
此前功能和短时真实客户端验收仍保留其原始身份。

## 成本模型与预测

回复延迟约为内核收发及调度＋协议解析/序列化，Request/Renew 另有租约状态与
文件更新。旧候选 Oracle 的 RS 为 C/Rust 0.251/0.167 ms，Solicit 为
0.431/0.180 ms，Request 为 0.427/0.141 ms；这只说明路径可能更快，不能预测
A53 的绝对值。本轮预测 Rust 请求路径不出现超过校准噪声的退步。

接口更新 CPU 约为 ubus 解码/dump＋有效配置比较＋RA 生成/发送＋等待期间后台
唤醒。Rust 有协议循环和 ubus worker，二者均有约一秒的到期检查；C 是 uloop。
因此更新和空闲 CPU 可能更差，是本轮最重要的未知数，不从回复延迟推算。
先前功能夹具 RSS 为 Rust/C 812/1112 KiB，预测同状态 Rust RSS 仍更低；新门
是逐对不超过噪声，**不再用旧的两倍内存上限代替**。任何反例均停止推进。

本轮直接测硬件，Oracle 只验证仪器功能。相较再做协议微基准或扩展功能压力，
该固定约五分钟批次能直接裁决四类用户指定指标，不追加优化实验。

## 固定身份和隔离

| 实现 | SHA256 |
|---|---|
| C（A） | `53e534a12d412b1f138ab95d15431bc109bbb356dbfadfb8625397d585d2be82` |
| Rust（B） | `c7c5f1f9e79ea80febe696d6c758db8d3463d1e4b94c7a002f1aa597b9c3ea30` |

每个样本独立 mount/net/PID/IPC/UTS namespace、只读根和私有配置/ubus。只创建
无物理端口的空 br-lan；不加载模块，不改现网配置、服务、接口、调频或 affinity。
各实例清空租约和协议状态，但不冒充整机冷缓存。namespace PID1 随控制进程
消失清除后代；整批另有限时 600 秒守卫。前后核对 boot、生产 C PID/ELF、配置
和客户端 TCP DNS/双栈 HTTPS。先核验离线备份、v0.2.3 恢复镜像及救援材料。

空 bridge 上收发是同硬件服务端对照，不是远端 Wi-Fi 客户端端到端时延。
私有 provider 提供真正的 `network.interface` 对象、订阅通知与 dump；其 DNS
变化触发原始 C/Rust 更新路径。不是实际 netifd 进程，也不测前缀变更成本。

## 固定采样

先在独立 namespace 测时钟和 UDP echo 地板，不启动产品，不扣除地板。
之后校准 `ABBAAB`，正式 `ABBABAAB`，共十四个全新实例；不并发测两个产品。
每个实例按以下顺序：

1. 对象就绪后安静 2 秒，零租约 RSS/RssAnon；固定 3 秒空闲 CPU 窗。
   空闲指无测试请求/通知，产品自身到期检查和周期 RA 照常运行。
2. 16 个 RS→RA；16 组 Solicit→Advertise、Request→Reply、Renew→Reply。
   三个固定 IA_NA 客户端轮换；保存所有请求、响应和逐事件时间，不删除离群值。
3. 补一个 IA_PD，取 3 NA＋1 PD 时的 RSS/RssAnon。
4. 八次 DNS-only 接口更新；每次 provider 通知后的 RA 必须含对应新 RDNSS。
   内核地址和前缀保持不变。CPU 窗从更新发起至匹配 RA 再加固定 1 ms 尾部，
   等待期间目标的背景 CPU 也计入，不减空闲值。

CLOCK_MONOTONIC 记录发送前与匹配接收后；AF_PACKET 观察关闭 multicast loop
的主动 RA。`clock_getcpuclockid` 读取目标全进程 CPU，包含 Rust worker，排除
provider、ubusd、观测器和子进程。CPU 不用 100 Hz `/proc` tick 替代。

每实例门值为各类 16 次回复延迟的中位数、八次更新 CPU 的中位数、3 秒实际
墙钟折算的空闲 CPU ns/s、两个阶段的 RSS 和 RssAnon。中位数定义在真机前，
全部原始事件仍保留；不按正式结果调整聚合方式。

## 噪声和停止规则

每个指标分别 `N = max(A 三个校准值极差, B 三个校准值极差, 2×实际量化)`。
量化采用实际单调/进程 CPU 时钟分辨率；空闲值按实际窗长折算；内存用实际
页大小 KiB，不把 `/proc` 文本的 KiB 单位误作一页以下精度。

正式四对按相邻 AB/BA 配对，计算 Rust−C；**任一指标任一对 > N，停止并汇报**。
等于 N 仍属本轮不可分辨。固定批次结束后分析一次；总体中位数只作展示，不能
抵消失败。仪器错误、超时、缺样或隔离失败也停止，保留不完整输出，不开第二批。
不设人为微秒门槛，不做 PGO。工具与 ELF 哈希随原始输出归档于 ignored private/。

本轮结束只裁决是否继续 v0.3.0；若通过，才重建/绑定新版本镜像和回滚材料，
不复用标为 v0.2.4 的旧候选部署包。若停止，报告具体数值和当前模型，不自行修补。
