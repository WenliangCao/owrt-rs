# R131 内存补测

R131 的空闲连接和大事件回退路径没有出现超过冻结门槛的新开销。
但 1 KiB × 八处理器事件触发了内存调查门：相对 R124，R131 保留的
**RssAnon 增加 12 KiB，VmData 增加 28 KiB**，两轮同值。
VmData 超过原先 +24 KiB 的护栏，本报告保留这个 flag，不把护栏改成通过。

原补测为精确 C/R124/R131/R131/R124/C 顺序，三个条件共 18 个路由器窗口：
空闲 0/1/8/32/64 连接、单处理器 32/256/768 KiB 大事件、单连接八处理器 1/8/32 KiB 事件。
每个连接数或 payload 使用新 daemon；事件在连接、完整交付、断开后各等待 1/5 秒采样。
所有功能、payload、handler、FD、生产身份和清理门通过。CSV 已逐项对账原始 `/proc` 快照，
18 个 raw archive 均与展开文件逐项哈希一致。生产始终为 C，没有安装候选。

下表事件条目为完成交付后保持连接 5 秒的 `RssAnon / VmData`；空闲连接条目为 holder 就绪后等待 1 秒。
单位 KiB，范围保留两轮的全部值。
RssAnon 是匿名驻留内存，VmData 是虚拟数据映射，两者不能相加或互相替代。

| 条件 | C | R124 | R131 |
| --- | ---: | ---: | ---: |
| 64 空闲连接 | 120 / 96 | 68–72 / 76 | 68 / 76 |
| 单处理器，32 KiB | 108 / 80 | 76 / 84 | 76 / 84 |
| 单处理器，256 KiB | 332 / 304 | 300–304 / 308 | 300 / 308 |
| 单处理器，768 KiB | 844 / 816 | 812–816 / 820 | 812 / 820 |
| 八处理器，1 KiB | 76–80 / 52 | 48 / 56 | 60 / 84 |
| 八处理器，8 KiB | 96 / 76 | 64–68 / 80 | 76 / 80 |
| 八处理器，32 KiB | 112 / 84 | 80–84 / 88 | 80–84 / 88 |

1 KiB 八处理器条件中，R124 和 R131 在 16 字节 warmup 后均为 `44 / 52`。
第一次 1 KiB 事件后分别变成 `48 / 56` 与 `60 / 84`，保持连接及断开后的 1/5 秒观察一致。
因此新增代价确实存在，不是一次采样抖动。相对 C，R131 的匿名驻留仍更低，虚拟数据映射更高；
不能据此声称“所有内存指标均优于 C”。

追加三个窗口保持各自同一个精确 ELF daemon，依次完成 1、1000、10000 个 1 KiB 八处理器事件。
每次均校验完整 payload、八个 handler 和 listener drain barrier；各平台等待 1/5 秒后记录 maps、status、FD 和进程身份。
三个窗口的 33 个快照全部对账，归档一致，功能和清理门通过。结果为：

| 累计 1 KiB 事件数 | C RssAnon / VmData | R124 | R131 |
| --- | ---: | ---: | ---: |
| 1 | 80 / 52 | 48 / 56 | 60 / 84 |
| 1000 | 80 / 52 | 48 / 56 | 60 / 84 |
| 10000 | 80 / 52 | 48 / 56 | 60 / 84 |
| 断开后 | 76 / 48 | 48 / 56 | 60 / 84 |

每格在 1 秒和 5 秒观察均相同；从第一个事件到第一万个事件，maps 文件字节也完全不变。
R131 的匿名可写虚拟映射从 connected 的 36 KiB 变为 68 KiB，R124 从 36 KiB 变为 40 KiB；
二者的 28 KiB 差与 VmData 差一致。因此这条固定负载下的额外开销在首个大事件后保持稳定，
没有发现随事件数持续增长。这个结论不等同于无限运行无泄漏，也不能覆盖变化 payload 的容量边界。

建议权衡：可以把实测的额外 12 KiB 匿名驻留和 28 KiB 虚拟数据映射作为已量化的固定代价，与性能收益一起评估。
原 +24 KiB 门仍被触发，调查结果不能把它改成“通过”，也不能替代其他功能或性能门。
本报告不给自动接受结论。没有 PSS、峰值、内核 socket 内存或九组件组合内存结果。
空闲连接脚本未归档 live exe/cmdline/starttime 和 FD 清单，该部分的身份证据弱于事件快照，不能等同描述。
