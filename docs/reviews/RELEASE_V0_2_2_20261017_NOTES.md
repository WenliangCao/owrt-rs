# v0.2.2 — 十组件安全边界与编译检查

本版统一交付 dnsmasq、procd、ubusd、netifd、rpcd、logd、httpd、fw4、uci、reload-config
的安全整理：业务 `src`（含共用 ubus）unsafe block **545→0**，业务 crate 强制
`#![forbid(unsafe_code)]`；实际路由器目标构建编译警告 **0**，CI 有编译警告即失败。
唯一新增第三方直接依赖为固定 **rustix 1.1.5**，既有 TLS 依赖不变。

必要的系统 ABI、信号、fork 和 FD 操作保留在 platform 封装，逐处说明安全前提；
shared platform 有 93 个 unsafe block、DNS 专用封装 63 个，UCI/fw4 的 libc 薄入口各 1 个。
不宣称标准库、依赖和诊断工具也没有 unsafe。保持 OpenWrt 25.12.5、AX3000T、原内核、
驱动、十组件原生路径、dnsmasq init/ACL 与配置迁移协议。

## 验收与性能范围

DNS 的 988 项原生测试、44 族/67 项实际正确性、no-proc/FD 和 shipping 边界通过。
另九组件 R92 完整 48 门、R93 的 9 组及额外 9 个功能窗口通过。验收抓到 procd
跨进程组回收回归，旧候选未部署；修复后完整 14 组复验通过，R71 计数恢复 1→2、
R83 恢复 11 次，与 C 一致。已有 C 行为差异及工具失败保留在[统一报告](CORE_SAFE_20261017.md)。
正式镜像的配置/恢复、APK 重装正负控、23 个自动回退分支、两种真实 PID1 升级交接、
带守卫的整栈启动检查全部通过。

按用户最终范围，只做 **24 个流量窗口（每场景 3 对）及 10 次启动**。各项未见可辨退化，
不宣称严格等效或提速，也未执行原计划的大矩阵或九组件新性能排名。
