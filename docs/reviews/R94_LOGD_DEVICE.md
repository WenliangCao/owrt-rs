# R94 logd 终版实机对照

2026-09-16，AX3000T。C 原版 / 正式 R89 / R94 终版 `08c833fd`（含 arena 环、模板帧、批量 pipe、burst-spin），
每侧四轮交错，**24 个观测全部校验通过**。生产为全 C 栈（R92 冷启动回滚后），负载在私有 namespace loopback，管理链路 Wi-Fi；
前后健康、boot、配置与栈身份一致。此前只有 stage-one 候选 `000f3f15` 上过机，本轮补齐终版。

单位 µs/操作，四轮统计中位数。

| 负载 | C CPU | R89 CPU | **R94 CPU** | vs C | vs R89 | C 延迟 | R89 延迟 | **R94 延迟** | vs R89 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| syslog_128 | 31.95 | 8.40 | **5.65** | −82.3% | −32.7% | 28.81 | 5.01 | **3.01** | −39.9% |
| log_read_100 | 809.50 | 420.50 | **121.00** | −85.1% | −71.2% | 1155.70 | 689.80 | **413.67** | −40.0% |

p95 延迟 C/R89/R94：syslog_128 30.28/10.81/**2.81**；log_read_100 1568.0/972.6/**649.1** µs。

负载后常驻内存中位数（KiB）：VmRSS C 1020 / R89 504 / R94 516；**RssAnon 240 / 174 / 120**。R94 匿名页比 R89 低 54 KiB，
关闭了 R93 source05 的 +64 KiB 差额；VmRSS 高 12 KiB 为文件页（候选 ELF 由 /tmp 载入，页类型不同）。fd 7、线程 1，与 R89 相同。

## 结论

两条固定输入负载上 R94 在 CPU、平均与 p95 延迟、匿名内存四个维度全部优于 C 与 R89，逐轮范围不重叠。
与 Oracle 四侧（160/160 字节相同、follow_8 优于 C 约 25%）方向一致。**logd 完成。**

## 边界

- 固定 128 字节 syslog 与读取 100 条两种输入；不覆盖整机真实日志正文、多读者 follow 与 kmsg 超长行（后两项由 Oracle 四侧覆盖）。
- 候选为 Oracle SDK recipe 诊断构建，非 canonical CI 发布；未部署。
- 原始逐轮样本与派生表：ignored `private/r94/device-r94-01/logd/`、`private/r94/device-r94-01-derived/logd/`。
