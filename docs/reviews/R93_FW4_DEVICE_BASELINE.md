## 验证与范围

- 每项每侧每轮 100 次计时操作、3 次预热，命令成功且 stdout 逐次字节校验通过。
- CPU 包含 fw4 命令及其子进程，原版 netifd/总线依赖固定；这是执行链成本，不是纯规则生成算法 CPU。
- 12 样本原始文件集合与 SHA 校验通过，共 180 文件；boot、配置、生产身份与客户端健康门通过，生产仍运行 R92。
- print/check 在隔离 namespace 内运行，未应用候选规则至生产网络。
- 固定简单 firewall/interface 配置；不覆盖大规则集、动态热插拔、reload/start 或完整启动链。
- source05 为同 SDK recipe 的 Oracle 诊断构建，非 canonical CI 发布。
