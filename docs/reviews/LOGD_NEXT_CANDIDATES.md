# LOGD 候选与拒绝索引

| 假设/变体 | 证据 | 决定 | 原因 |
|---|---|---|---|
| normalize 一次 ASCII 优先级解析 | 2M 随机输入逐样本相等；函数 release 微基准约 -4.6%；unit/clippy/CI/设备 smoke 和正式四侧通过 | **保留** | 代码小、语义边界明确；设备 syslog CPU 与 R94 重叠，收益不夸大 |
| `Client::queue` 延迟压缩，模拟 ustream 阈值 | 上游机制成立；本轮未实现 | **拒绝本轮引入** | 会改变容量/预算边界，缺少独立快慢读者计时；R93 follow_8 只提供机制线索 |
| Ring::add 无 LF 快路径 | 源码差异已定位 | **不做** | C 也先扫 LF，预期收益小于解析候选，未有足够区分度 pilot |
| handle_read 单遍统计/编码 | 双遍成本已定位 | **不做** | 需要维护额外长度状态，当前主要收益已来自既有模板帧，尚无必要复杂度证据 |
| kmsg drain-to-EAGAIN / cursor | C 回调会处理多行；Rust 当前有公平上限 | **不做** | 会触及唤醒公平和生产 kmsg 替身边界；没有新的可控设备输入证据 |
| burst-spin 继续调参 | 现有 4 次 zero-timeout 已经是 R94 实现 | **不做** | 稀疏输入空闲 CPU 与尾延迟权衡未证明值得调整，禁止无限自旋 |
