# 整机网络性能：测量计划

2026-09-29，用户授权按系统性能、针对性优化、固件维护三步推进。基线为 AX3000T Rust9 v0.1.0。用户提供 Windows 电脑接 LAN，Mac 保持 Wi-Fi；配置调整取决于基线证据。

## 路径与判读

1. Mac Wi-Fi ↔ Windows LAN：测无线加桥接路径，绕开宿舍外网。此结果不是 WAN/NAT 转发吞吐，也不是纯有线转发。
2. Mac Wi-Fi ↔ 自有远端测试主机：测无线、路由转发和上游网络组合。只有确认测试端口直达且服务器有余量才执行。
3. 必要时路由器 ↔ 远端：排除 Wi-Fi 的诊断对照，测试进程自身占用路由器 CPU，结果不得标为纯转发能力。
4. 纯有线 LAN→WAN 上限需要有线客户端和适当 WAN 对端。现有路径达不到该条件时明确留空。

## 固定方法

- iperf3 3.21；Mac 与 Linux 构建使用 ESnet 原始源码包，SHA256 `656e4405ebd620121de7ceca3eaf43a88f79ea1b857d041a6a0b1314801acdd8`。Windows 使用已向用户说明的 ar51an 3.21 便携构建，记录版本。
- 首先短请求验证路径；正式 TCP 每次 15 秒，预热排除 2 秒，4 条并行流，双向分别测试，每方向三轮，顺序 upload/download 交替。每个进程有限时；失败原样保留，不择优替换。
- 记录接收端吞吐、发送端重传、端点 CPU（iperf 提供时）、路由器每核 CPU/softirq、接口字节和无线 station 计数前后差值。无线重试次数不是 IP 丢包率。
- Mac ICMP 到路由器的初次检查无回复，但 HTTP 可达，故不把该现象当作链路丢包。使用同一 Mac 到路由器 HTTP 端口的 TCP 建连时间，标明它包含客户端调度与无线链路，不冒充 ICMP RTT。
- 每批先采集 10 秒空闲 TCP 建连，再在负载时每 0.5 秒采集一次；样本数不足以作精确 p99 结论，报告中位数、p95、最大值和失败次数。
- 原始 IP/MAC/进程/输出进入 ignored `private/datapath-20260929/`，公开派生报告只保存角色和统计值。设备上不安装常驻采集服务。

## 优化与停止条件

只选择基线指出的瓶颈。软件/硬件流量卸载、WED、SQM 分别对待；桥接吞吐不能用来证明 WAN 硬件卸载收益。任何配置候选单独改变，保存原值，验证恢复动作和客户端健康后才进行 A/B 对照。没有明确收益就保留基线。当前阶段不刷写固件。

测试结束关闭临时进程，清理临时设备文件，核验配置和九组件身份。发布工具与固件维护可独立在开发机完成。

## WAN 路径补充（正式 CPU 测量前）

自有远端的 TCP 15201 连接超时，未修改远端网络规则。改用 macOS 自带 `networkQuality -M 25 -I en0 -c` 的 HTTPS 双向同时负载，包含 Wi-Fi 与公网，不能当作纯有线转发上限。初次文件参数错误和随后成功的连通性 pilot 分开保留，不当作正式 CPU 对照。正式基线固定三轮，记录每轮网络指标、每核 CPU、无线计数与 TCP 建连延迟；每轮之间休息五秒。RPM 是该工具定义的响应性分数，不等同于 ICMP RTT 或 p99。采集随实际负载结束停止，避免把工具提前完成后的空闲时间计入平均负载 CPU。

## 硬件卸载候选（B 窗口开始前）

软件卸载基线三轮中，整机 CPU 为 62.6%～65.1%，忙核为 76.6%～83.3%。因此只选 `flow_offloading_hw` 作为本轮配置候选，WED、信道、SQM 和 packet steering 保持不变。通过临时 UCI 选项生成的 Rust/C 候选规则逐字节一致，内核检查接受硬件标志；该预检结束时配置已恢复，运行规则未改变。

对照顺序固定为现有 A 三轮 → B 三轮 → 恢复 A 三轮，每轮使用上述相同的 HTTPS 工具参数。候选只使用临时 UCI 修改；先验证独立计时器和恢复命令，候选窗口最多 180 秒，测试结束立即恢复。正式运行前检查配置备份、无其他待提交改动、客户端健康。中途连通失败则停止并恢复，不补选慢轮。

筛选要求：观察到真实硬件卸载连接；相对前后 A 中位数，CPU 至少降低 15%；下载和上传各自的中位数均不降低超过 10%；TCP 建连失败数不增加且 p95 不增加超过 20%。这些是工程筛选阈值，三轮不构成普遍性能保证。若前后 A 漂移明显或机制没有生效，则保留原配置，结果记为无效益证据或未决。

交互中断记录：用户要求放慢两台电脑之间的操作节奏时，首次 B 完成两轮，第三轮被停止；已恢复原值并清理临时文件，原始结果全部保留，该批不作为完整对照。随后 Windows 防火墙配置完成；同一 Mac iperf 程序从代理启动失败、从系统 Terminal 启动成功，正式 LAN 六次测量由 Terminal 完成。局域网完成后，重新固定执行一次完整 A₁ 三轮 → B 三轮 → A₂ 三轮，使用新目录 `wan-final-software-before`、`wan-final-hardware`、`wan-final-software-after`。重开完整对照是为了接续人工中断并取得相邻参照，不合并旧轮次或按快慢筛选。
