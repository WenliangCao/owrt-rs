本版把基础镜像、SDK、ImageBuilder、包与 LuCI 输入切换到25.12.6；保留25.12.5
历史配方和已有冻结身份。源码收录微软 Rust 规范审查后的安全、错误处理、测试
可靠性修复，以及业务 `forbid(unsafe_code)` 的平台边界返工。
用户向变更见[发布说明](../releases/v0.3.3.md)。

验证链：

- [官方输入与离线准备](V033_OFFLINE_PREPARATION_20261023.md)：SDK/stock/ImageBuilder
  实际 SHA 校验；新包库存与 LuCI 中文目录；精确升级脚本的 UBI 路由模拟。
- [构建入口](V033_MBX_BUILD_ROUTE_20261023.json)：所有实际 Rust 构建经过`mbx`，
  保留真实 Cargo/Rust 1.98.1 身份及原始编译参数。Mac未编译Rust。
- [前端组件](V033_CANONICAL_FRONTEND_20261023.json)与
  [其余组件](V033_CANONICAL_NETWORK_20261023.json)：实际canonical ELF在精确.6
  镜像内回归；[第二次core构建](V033_CANONICAL_CORE_REPRO_20261023.json)的10个ELF
  与这批已验收字节一致。
- [新PGO资格](V033_DNSMASQ_PGO_QUALIFICATION_20261023.json)：新插桩程序、一次完整
  11场景／50profile训练、实际候选44类／67项、F23/F25各四轮、无proc及FD压力、
  40次启动和ASLR/RELRO/NX；[frozen-use](V033_DNSMASQ_PGO_REPRODUCTION_20261023.json)
  的ELF、APK和link map全部逐字节重现。
- [双镜像复现](V033_IMAGE_REPRO_20261023.json)：固件、5个APK、11个实际内嵌ELF、
  CONTROL、FIT/kernel、rootfs和最终manifest全部相同。两份各40条CI校验和均有效。
  不声称原始artifact ZIP或所有诊断JSON相同：4处附属字段差异已列出；未发布的
  中间镜像及未上传的cargo-identities文件缺少原字节，不推断其内部差异原因。
- [最终离线验收](V033_OFFLINE_QUALIFICATION_20261023.json)：FIT、用户态PID1启动和
  IPv4/IPv6客户端、image11、APK2+8负控、guard23、normal/70秒慢停handoff、
  rollback46原成员/13恢复文件、log16全部通过，另有NAND5正控/1负控。
  原始rootfs整树、工具和输入在验证前后不变。

已知边界保持明确：极低FD条件下helper失败与新跑的v0.3.2一致，没有涂成操作成功；
已有C差异保留，没有承诺所有微路径零性能回退。夹具遮蔽`/proc/kmsg`、禁用私有
副本中的硬件hotplug规则并使用只读sysfs，详见[隔离记录](V033_NAMESPACE_ISOLATION_20261023.md)。
这不是物理内核启动、Wi-Fi或真实NAND写入验证。离线备份是非当前夹具，不能部署；
未来刷写仍需当次授权、真实新备份、恢复门和客户端健康验证。

失败记录完整保留：首轮SDK构建在编译前被mbx过长临时socket路径拒绝，修复后重新
冻结输入；旧清单测试的.5默认值与.6环境不一致已修正。另两次生成任务分别在环境
等待后的取消请求和30分钟上限下终止，不计成功。旧logd夹具的4MiB/1MiB假设被
实际v0.3.2/current合同否定后补充真实负载及负控，产品代码未变；最小隔离测试首次
误设镜像自带stat命令，修正夹具后重验，最终完整镜像门禁无失败。

发布采用第一轮CI原始字节，不为发布重建。13个公开附件按以往命名约定准备，
中文APK的`~`仅在公开文件名中替换为`.`；原CI清单保留为`CI-SHA256SUMS`，
另生成覆盖公开附件的`SHA256SUMS`。13个附件在草稿及公开后均完整下载回读，
字节、外层校验和及GitHub asset digest全部一致；release-image已恢复active，
核验时没有多余tag构建。见[发布收据](V033_PUBLICATION_20261023.json)。
