# RPCD 同进程资源生命周期三方验证（2026-09-28）

设备：Xiaomi AX3000T / MT7981B，OpenWrt 25.12.5。比较精确镜像 C、正式 R89 和 canonical 候选；本页只报告资源实验，不替代延迟、吞吐或完整兼容合同结论。

本批候选第 4–10 轮释放后 RSS 为 **1300 KiB**，高于正式 R89 的 **1220 KiB，+80 KiB（+6.56%）**；低于精确 C 的 **1932 KiB，−632 KiB（−32.71%）**。候选释放后匿名页为 176 KiB，对 R89 +12 KiB（+7.32%），对 C −412 KiB（−70.07%）。

候选释放后 RSS 前四轮为 1228、1280、1288、1300 KiB，累计增加 **72 KiB**；第 4–10 轮维持 1300 KiB。匿名页同期 104→176 KiB，也增加 72 KiB。这里只描述本次十轮中的初始增长和随后平台，未测得分配器因果，也不据此宣称所有负载均无泄漏。最终对 R89 的 80 KiB RSS 差额在该快照中由匿名页 +12 KiB、RssShmem +68 KiB、RssFile +0 KiB 组成；这同样不是原因归因。expanded 第 10 轮 RSS 为 1680 KiB，较第 4–9 轮的 1676 KiB 仍高 4 KiB，因此不能把释放后平台扩展为所有阶段均无增长。

执行顺序固定为 C→R89→候选，每侧只有一个 daemon 启动，十轮共创建并销毁 640 个会话。每轮每会话 16 条 ACL、2 KiB 数据；扩容快照前读取并核验隔离配置的 64 个 UCI 节。active 为当轮第一个已填充会话，expanded 为 64 个已填充会话且完成 UCI 读取，released 为全部销毁后等待 1 秒。startup 仅采一次。三侧保持原生产栈，主体只运行于独立 namespace。

内存单位均为 KiB；fd、线程、子进程为数量。CPU、PSS/USS、内存映射明细及连续 RSS 峰值 **缺测**。子进程列是快照时 PPid 指向被测进程的直接子进程数，不是全过程 fork 计数。本表仅列采样点；同侧十轮不是十个独立启动，也不作跨启动显著性推断。百分比为候选减基线除以基线；基线为零时百分比留空说明，不填 0%。

`VmHWM` 原始报告在同 PID/start_ticks 下出现下降，例如 C 2268→2056、R89 1596→1564、候选 1616→1440。保留这些观测值，**不把 HWM 列或其最大值解释为可靠单调的全程连续峰值**，也不据此宣布峰值内存胜负。

### 恢复门与运行隔离

运行前核验离线备份、生产配置与备份一致、同一设备启动身份和客户端 Wi-Fi 健康。三侧主体使用独立 mount/PID/network namespace，统一精确 C ubusd 依赖，600 秒 guard 限制 namespace 存续；临时产物和输出写入每侧独立 UUID `/tmp` 目录。正式 R89 `/root/r89-before-r90` 原件只读。测试只调用 session create/grant/set/get/access/destroy 和隔离配置 UCI get，不执行 UCI apply/commit、服务控制、升级、刷写、重启或生产进程替换。

每侧完成后确认临时进程和目录已清理，重新检查客户端健康、生产九组件身份、配置、启动和宿主 mount 状态；三侧均通过。恢复门与资源采集使用的具体身份在上表和哈希记录中冻结。资源生命周期通过不能代替断连、超时、apply/rollback 等其它恢复合同的结果。
