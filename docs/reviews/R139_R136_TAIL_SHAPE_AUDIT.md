# R139：R136 原始尾延迟形状只读审计

**四个尾部负项继续成立；现有数据把问题缩小为不同的分布形状，尚未给出根因。**
本次没有运行 benchmark、访问路由器或修改候选。只复算原 R136 主矩阵的
五条生命周期负载，共 16 窗 × 5 条 × 10,000 周期；没有删窗、删样本或改变验收。
追加分位数、周期分块和相邻尾部概率都是事后探索，不产生新的胜负结论。

register_1 在 p80 已出现较高肩部；event_1 与 event_nomatch 到 p85 仍较快，
随后交叉。这不是共同的全分布平移。额外分位数本身也不足证明混合模态或其机制。

继续使用原八个不复用相邻配对，以每对 C 的 p95 为阈值，候选超阈周期比例的
八对中位数分别为 register_1 **9.905%**、event_1 **7.795%**、event_nomatch
**7.625%**；register_16 为 4.565%、event_8 为 2.560%。每窗保留原 10,000 周期，
未把差窗口移出比较。分块结果仅提供诊断线索，不是额外独立重复样本。

## daemon 切换计数不能提供共同解释

以下是每个完整 10,000 周期窗口的边界计数差，再取八窗中位数。

| 负载 | voluntary C / R136 | nonvoluntary C / R136 |
| --- | ---: | ---: |
| register_1 | 19,949 / 18,696.5 | 139 / 2,599 |
| register_16 | 19,958.5 / 19,853.5 | 141 / 223 |
| event_1 | 19,983.5 / 19,958 | 96 / 87 |
| event_8 | 19,993 / 19,966.5 | 127 / 97.5 |
| event_nomatch | 19,972 / 19,974 | 46 / 40 |

register_1 的八个候选窗 nonvoluntary 均为 **1,929–3,583**，八个 C 窗为
**92–1,133**，存在明确的描述性分离。event_nomatch 的候选 03/06/07/11 窗
只有 8–50 次 nonvoluntary，却仍呈现超过各自配对 C 的 p95。
因此不能把四项负值合并解释为“daemon 抢占次数增加”。这些边界计数无法确定
哪次切换发生在尾周期，更不能换算等待时间；caller 调度、跨核唤醒及 daemon
内部服务成本目前也无法从这些数据区分。

## 早期周期较重，但慢尾不只在启动阶段

按每窗自身 p95 定义严格大于阈值的尾集合，候选首 1,000 周期占全部尾样本的
比例中位数为 register_1 **18.5%**、event_1 **14.315%**、event_nomatch
**18.0%**，C 分别为 11.5%、10.8%、11.311%。候选早期确实较重，但大部分尾样本
仍在后 9,000 周期。

原八对 × 十个连续 1,000 周期块中，候选超过配对 C 全窗 p95 的比例高于 5% 的
块数为 register_1 **67/80**、event_1 **69/80**、event_nomatch **68/80**。
它们分布在循环过程中，不能靠删除头部少量样本宣称修复。
周期块不是等时长块；原样本没有逐周期绝对时间戳，不能与宿主事件精确对齐。

## 最小的后续区分

冻结 harness 的执行顺序是 register_1、register_16、event_1、event_8、
event_nomatch；daemon 固定 CPU1，但生命周期 caller 没有显式 pin，实际继承
的 affinity 与迁移未被原证据记录。register_1 还是新 daemon 的第一条负载，
只有 20 次预热，负载身份与 daemon 年龄并未解耦。

下一次若获准采集，应保留原 formal 请求路径和 cycle 计时边界，先补 caller 的
窗口前后 affinity、CPU 位置与 context-switch 计数；另设 CPU0 caller 的诊断臂，
与保留原放置策略的控制臂成对比较。边界信息只提供窗口关联，仍不能定位逐周期
调度；CPU0 臂是干预实验，不能替换原正式验收结果。固定 caller 后若 register_1
肩部消退而 event_nomatch 尾项仍在，才有证据拆成两条机制路线；否则继续检查
共享生命周期路径。不要先改 REMOVE 合并或再给每周期插入 CPU 时钟读数。

R137 换 caller 且加相位读数后未复现原尾项，因此新诊断必须先报告自身的原路径
控制臂是否复现。也不能直接把更长预热当修复：要测试年龄效应，需独立控制执行
顺序/预热，不能事后截去已有样本。
