# M5 与 C 的行为差异

本表记录用户明确接受的实现差异。各功能族的原版缺陷和极端输入延期仍按交付账本及对应原始证据保留；未执行的场景不算通过。

| 选项 | 镜像 C | Rust | 理由与验收边界 |
| --- | --- | --- | --- |
| `log-malloc` | 启用 `whine_malloc/realloc/free` 等包装器的分配日志，包含 C 调用函数、行号、尺寸及实际指针的低 24 位。 | 接受选项，保持启动和 `--test` 合同；不输出逐次分配日志。生产程序不使用全局分配跟踪。 | 按用户 2026-10-06 更正：Rust 的分配方式、源码调用位置和地址与 C 不同，分配日志内容不要求一致。启动的其他日志、退出、资源和语法结果仍须实际 C 对照。 |

全局分配跟踪实验保存在 `archive/m5-malloc-trace-experiment-20261006`，已从生产代码撤下。实验给所有普通分配增加开关检查和包装调用，并引入约 128 KiB 静态事件缓冲；首次 ELF 增量 180,224 字节，约束内联的独立控制省下 143,360 字节。撤除后的体积将绑定新候选实测；实验记录不能当作生产跟踪功能资格。
