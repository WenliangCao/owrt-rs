# 性能协议 v1（测量前冻结）

本版在首次 C/Rust 成对性能结果之前冻结。修改负载或门槛必须升版并说明原因，
不得用新门槛重新解释已看到的结果。功能未通过的场景不进入性能验收。

## 主目标与环境

主要收益目标：缓存/正常混合/DHCP 续租三组 CPU/完成操作的几何均值下降至少 15%，
且混合负载与 DHCP 150 租约稳态的私有内存峰值至少下降 10%。各组不得靠额外错误、
丢弃或延迟工作取得收益。重要场景 CPU 或 p95 恶化超过 5%，或私有内存增加超过
`max(64 KiB, C 的 5%)`，均需定位与改进；不得自行忽略。小于噪声的差异写未证明。
吞吐下降超过 5% 也阻止验收。资源预算必须相同。

原生主机用于筛选；匹配目标 ELF + 隔离 rootfs 用于功能；真机性能单独授权后测量。
三种环境的结果分表，不交叉计算加速比。当前物理设备实验未授权。

## 固定输入

所有域名为合成 `.test`，地址使用文档地址段，随机种子 `0x293001`。
缓存容量 1000，EDNS 1232，max-forward 每组 150，正 TTL 120 秒，负 TTL 30 秒，
相同 rebind/源匹配检查、源端口随机化、TCP/FD/租约上限。禁止关闭安全检查换收益。
受控上游同时提供 IPv4/IPv6 UDP/TCP，响应内容与延迟固定，单独计数 CPU。

| 场景 | 固定操作 | 输入与计量边界 |
|---|---|---|
| DNS 热缓存 | 100k 完成查询/轮 | 800 名字，A/AAAA 70/30，预热不入测量，客户端并发 32 |
| DNS 未命中 | 20k 查询/轮 | 唯一名字，上游固定 1ms 延迟，并发 32 |
| DNS 正常混合 | 100k 查询/轮 | 70% 命中、20% 唯一、10% 负回答，A/AAAA 70/30，并发 32 |
| 上游失败 | 10k 查询/轮 | 90% 正常，10% 第一上游丢弃，第二上游正常；计重试、所有超时 |
| TCP | 20k 查询/轮 | 8 并发连接，每连接 100 次；另记建连与关闭成本 |
| DHCP | 10k 续租 + 150 次 DORA/轮 | 150 合成客户端，12h 租约，原 leasefile/DNS/事件语义 |
| 重载 | 100 次/轮 | 1000 hosts、150 租约；测信号至名字可见与缓存重建，保留文件I/O |

单轮功能校准先以小样本验证计数器：正常应成功、错误注入应被计为错误、超时应计为
超时，工具退出非零。性能窗口禁止查询日志、抓包、fuzz、编译或其他代理负载。

先测 C 的完成吞吐上限，C/Rust 等交付负载固定为其 70%。客户端按预定发送时间发出，
同时记录予定时间至完成和实际发送至完成的延迟；不以响应变慢自动降低发包量。
容量测量另列，并发 1/8/32/128，每档相同操作数，不把容量点当稳态尾延迟。
预热 5 秒，正式窗口至少 10 秒且达到上述操作数。五轮交错 C/Rust、Rust/C，
首轮顺序由固定种子选择；全部轮次入报告，失败窗口保留并明确原因。

## 计量

逐轮保存输入/配置/二进制/编译参数哈希、计划/发送/完成/成功/错误/超时数量、
客户端延迟样本、服务与依赖 `/proc` CPU 时间增量、上游请求量、RSS/PSS/USS、
FD/线程/子进程峰值、文件字节及最终大小。p50/p95 始终列；有效样本 ≥10k 才列 p99。
CPU 以服务进程树的 user+system 增量/成功完成操作计，依赖、发生器、上游另列。
RSS 仅作为共享映射在内的驻留量，不能代替 USS/PSS。

30 分钟稳定混合与租约更新窗口每秒采样，最后 10 分钟对最初稳定 10 分钟比较
FD、私有内存、记录数趋势；退出后验证所有子进程、socket、临时租约与FD释放。
产物报告 stripped ELF、APK 大小和只读/可写 section；不能以压缩 APK 代表运行内存。

## TFTP 局部候选（独立于主目标）

C `get_block()` 对每个 LF `memmove` 尾部，最坏 O(B²)；Rust 顺序写入 O(B)。
先用原 C 函数逐字节及 continuation state 对照，再测试 blocksize 512/1468/4092、
无 LF、每 80 字节 LF、全 LF 三种固定数据，每组 1M 次，五轮交错。
计耗时/CPU 和输出 checksum；ASCII 或正常文本退步 >5% 则调整或撤回。
这是单个函数候选，不作为 DNS/DHCP 主收益或路由器性能结论。
