# DNS runtime safety review

Coverage:17 production files; separate test files and inline test modules are excluded from mechanical panic cleanup. No Mutex exists in this scope. Main, daemon and tcp_service remain root-owned; changes to them are delivered as canonical patches.

| File | Retained invariant or safety proof |
| --- | --- |
| `dns/cache.rs` | Cache owns private slots, LRU/name/reverse indexes and validates generation handles before use. Insert/link methods check handles; index lookups refer to occupied slots, and retirement removes each index before freeing the slot. Checked u64 identities prevent wrap and dangling CNAME aliases; exhaustion requires 2^64 allocations and is an internal invariant failure, not a packet field. Reverse names are generated from fixed-size IP octets and stay below DNS label/name limits. |
| `dns/cache_engine.rs` | Reverse lookups return generation-validated live handles and the single mutable borrow excludes concurrent retirement. Address slice conversions occur only in exact4/exact16 length branches; generic records use checked canonical_rdata and propagate malformed/too-long errors. |
| `dns/cache_reply.rs` | Entry handles are validated by callers before helpers; helpers only read cache records while the same cache borrow remains live. Writer failures are returned, not converted into cached packets. |
| `dns/forward.rs` | Pending IDs are found in the question/ID index before get_mut; retirement removes indexes before slots are reused. Generation checked_add prevents aliasing stale IDs; exhaustion is a 2^64 lifetime invariant. Reply admission checks original ID, question/type/class, socket ownership and40-second age. |
| `dns/forward_service.rs` | Submit checks routing membership; table.submit returns a live pending handle, then plans against the retained group. Source replacement rebinds IDs or explicitly retires server-owned requests. Reply-side live-server fallback keeps routing exclusion separate from endpoint/socket authentication. |
| `dns/upstream.rs` | Sockets/transactions/probe queues are owned by one event loop and all tokens come from those maps. Nonempty compatible lists precede last(); pooled sockets alone have slots and a nonzero pool bound; counted queue loops precede pop_front. pollable_at(false) requires an existing retry timestamp. Successful send/match precedes pending lookup/finish. Literal wildcard addresses parse infallibly. Existing SAFETY comments cover live timespec/pollfd buffers and ABI types; no Mutex. |
| `dns/source_sockets.rs` | Added per-operation SAFETY proofs for CString lifetime, scalar sysconf, repr(C) sockaddr layouts, bounded setsockopt buffers, fresh-descriptor transfer and fcntl ownership. Every error drops OwnedFd. Runtime negative-1 capacity yields zero pool rather than unsigned expansion. Socket port arithmetic relies on scalar.finalize_runtime range validation; public settings are the validated socket configuration contract. |
| `dns/tcp_upstream.rs` | No runtime unwrap/expect or unsafe. TCP framing/deadlines are checked and errors remain explicit; transport state is connection-owned. |
| `dns/wire.rs` | u32 fixed conversion is preceded by checked record/header bounds at every call; four-byte slice length is exact. PacketWriter starts with12-byte header and only appends or trims whole records after it, so finish retains the header. Canonical RDATA has checked u16 size; compressed names have bounded pointer traversal and wire/name lengths. |
| `neighbors.rs` | Existing SAFETY comments cover fresh netlink FD ownership, initialized sockaddr/request structures and writable recvmsg buffers. Dump state is present whenever dump polling runs; take closes one completed dump. Header/attribute conversions follow16/12/4/2-byte remaining-length checks; AF4/AF6 values require exact4/16 bytes. No Mutex. |
| `dns/edns_policy.rs` | Pseudoheader offsets come from validated find_pseudoheader; fixed4-byte TTL slices fit the OPT header. ECS address output contains ceil(mask/8) bytes and last_mut is used only for nonzero remainder, so it cannot be empty. TLV helpers check at+4 and payload length before fixed conversions. |
| `dns/doctor.rs` | Name traversal and fixed+10 checks precede RR fields; data slice is checked to rdlen and IPv4/IPv6 conversions require exact4/16 bytes. Malformed records return an error before address rewriting. |
| `dns/tcp_exchange.rs` | Active/waiting phases are entered only after storing a connected stream; all clear/error transitions reset both phase and connection. Two expect sites express that private state-machine invariant, not assumptions about remote packet input. |
| `dns/routing.rs` | A bucket is created before last_mut; only upstream SourceRule entries receive/use server identities, and replacement assigns them before publication. Domain/local-only rows bypass upstream identity paths. |
| `dns/files_runtime.rs` | Host directory scans run only after watch initialization. Endpoint expansion/update fields are installed together and retired together; counted error queues precede pop_front. Endpoint groups are created before adding their member rows. if_nametoindex SAFETY documents live C-string lifetime. File errors remain explicit diagnostics. |
| `dns/filewatch.rs` | Existing SAFETY comments document fresh netlink/inotify ownership and live sockaddr/C-string/read buffers. Truncated netlink/inotify headers are rejected before fixed2/4-byte conversions; supplied payload lengths are bounded to remaining bytes. Rejected frames never publish partial route state. |
| `dns/local.rs` | The sole runtime address conversion is in an exact16-byte AAAA branch. Local answer construction uses checked writers; lease/interface generations are read in the single owner. No unsafe or Mutex. |

Changes: source socket FFI SAFETY comments and signed empty-pool conversion; deterministic signed negative capacity startup failure is delivered separately. The oversized SOA canonical representation is intentionally rejected rather than reproducing C unsigned-short truncation. Targeted ABI/pool test and fresh exact-image edge calibration are recorded in private M5 evidence.
