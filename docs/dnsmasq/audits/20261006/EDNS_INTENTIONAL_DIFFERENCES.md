| Cases | Matching C source and mechanism | Retained Rust behavior and reason |

| `coalesce-ecs-distinct-ip`, `coalesce-mac-distinct-ip`, `coalesce-umbrella-distinct-ip` | `forward.c:181-218` calls `lookup_frec` using question/class/type and header flags, then retrieves the first query stash. `forward.c:3227-3263` compares that question/header mask, without comparing effective source identity option bytes. `forward.c:1948-1952` decorates the query through `edns0.c:560-575`. | Source-dependent effective EDNS bytes scope coalescing.
