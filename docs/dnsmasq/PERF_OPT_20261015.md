## Performance mechanisms

- DNS name validation avoids constructing decoded names whose callers discard
  them. Local answering reuses one dotted query name. Configured CNAME matching
  compares against the existing wire key without allocating each alias.
  A query-local cache hint reuses prior inspection only while cache identity,
  revision, slot generation and query identity remain valid; multi-record
  lookups retain the original loop. Expiry and LRU effects still occur at lookup.
- Cache insertion computes escaped name length without a temporary byte vector,
  and copies the original name only when reverse indexing uses it. Cache clearing
  checks COW once per block and reuses only unique, empty, zero-capacity roots;
  it does not move required startup allocation to the first query.
- DHCP hex serialization uses bounded stack chunks with identical bytes/error
  handling. Its 4,665→2,400 calls are writer calls, not kernel syscalls. Lease
  publication borrows canonical keys, stores singleton indices inline and shares
  immutable name bytes. Active flags and expiry remain local to each generation.
  Hosts keeps a count instead of an index vector and shares a bucket calculation
  only within one publication call; original blocker scans/rotation remain.
- UDP input is borrowed until a deferred consumer needs ownership. TCP framing
  keeps the existing packet and a separate length prefix, removing a second
  allocation/copy. Upstream polls reuse scratch vectors. Creating UDP sockets
  with NONBLOCK/CLOEXEC removes two setup syscalls per socket while preserving
  source-port selection and failure cleanup.
- Final successful process exit retires only pure cache memory after explicit
  helper/log/PID cleanup. IO destructors still run. Startup does not skip any
  required initialization or validation.

Resource tradeoffs remain part of device acceptance: TCP may retain the answer
vector's spare capacity; poll scratch retains 16 bytes per observed maximum
socket plus 48 inline bytes. Oracle's native atomics cannot establish A53 costs
for shared lease names. E's observed memory/FD costs are reported above; future candidates need fresh resource gates.
