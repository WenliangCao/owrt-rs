Research in progress. No optimized candidate is qualified yet. The fresh complete
baseline contains **110/110 valid windows** (11 scenes × five alternating pairs),
verified from raw archive/file hashes. Both C and deployed v0.2.0 were measured
anew; no historical C or Rust observations are pooled. The deployed original is
SHA256 `8472be5a…`; the historical `50e591a9…` ELF is not the baseline.

The user explicitly authorized independent compatibility fix `b1136023` on
resuming this task: correct the existing expired-negative-CNAME stale metadata
and background-query defect to match exact C. This behavior correction is
separate from performance changes; frozen C expectations remain unchanged.
