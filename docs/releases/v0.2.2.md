# v0.2.2：10 组件安全整理 · OpenWrt 25.12.5

本版对 procd、ubusd、netifd、rpcd、uci、reload_config、logd、uhttpd、fw4、dnsmasq 共 10 个 Rust 组件做安全整理。业务源码中的 unsafe block 从 545 个降为 0，业务 crate 禁止 unsafe；必要的系统调用和 ABI 操作集中到平台封装。目标编译警告为 0，并加入 CI 检查。平台封装和依赖仍含 unsafe。

本版与上一版的短回归比较包括 24 个流量窗口和 10 次启动，未见可辨退化；没有重新测量各组件与 C 的性能。dnsmasq UDP 命中 CPU 的三个配对均小幅增加，中位增加 2.173 µs，低于本轮 5.45 µs 的版本内跨窗范围；不据此声称性能等价或提速。
