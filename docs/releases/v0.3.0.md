# v0.3.0：新增 odhcpd · OpenWrt 25.12.5

本版新增 odhcpd 的 Rust 实现，共提供 11 个 Rust 组件；其余 10 个组件沿用 v0.2.3。

odhcpd 支持 RA/SLAAC、DHCPv6 IA_NA/IA_PD、租约及租约触发器、UCI、ubus dhcp 对象，以及 netifd/内核前缀更新。空闲时按事件或到期时间唤醒，ubus 断开后可重连。NDP 代理、中继及 odhcpd DHCPv4 服务不在支持范围，配置这些功能时拒绝启动；DHCPv4 继续由 dnsmasq 提供。未实现 DHCPv6 Reconfigure。

odhcpd 数据来自最终发货程序与 C 的隔离设备对照，列出正式样本中位数。netifd 沿用 2026-10-17 同一程序的系统调用计数，其余未有对应 C 测量的项目写“未测”。

表中“C 原版”指 OpenWrt 原实现；fw4 原版为 shell/ucode。

odhcpd 的 10 项指标、40 个配对中，39 个改善超过校准噪声，1 个 Renew 配对在噪声内，没有触发退步条件。空闲的 0 仅指三秒窗口内未记录到 CPU 增量，不代表永久零 CPU。测量使用隔离空网桥和本地客户端，不代表 Wi-Fi 往返、整机启动或首次主动 RA；IA_PD 正确性另由实包夹具验证。完整数据见[最终 A/B](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/ODHCPD_FINAL_FULL_AB_RESULT_20261018.md)。

已完成保配置刷写和真实客户端自然 DHCPv6 续租验收，续租前后 IPv6 地址、路由、DNS 正常。一次受控 WAN6 断开时，路由器约一秒发出旧前缀撤销 RA，离线确认撤销字段与 C 一致。Mac 到恢复初期才标记地址弃用，随后恢复同一前缀；这不证明客户端立即删除旧地址，该延迟已接受。长观察中另有一次续租验收窗口外的 dig 失败，具体命令和原因未确定，后续检查恢复通过。详见[部署记录](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/ODHCPD_V030_DEPLOYMENT_20261018.md)和[撤销报文对照](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/ODHCPD_WITHDRAWAL_C_PARITY_20261018.md)。
