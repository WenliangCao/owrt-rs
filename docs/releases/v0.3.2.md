**仅适用于原厂 bootloader 布局、AN8855 交换芯片版本的小米 AX3000T；不适用于 MT7531 版本或 ubootmod。**

## 改动

- **启动与日志**：DTB 禁用本硬件不存在的 MT7531，向原 U-Boot 参数追加 ` loglevel=4`，保留 firmware、mtd 等全部原参数和 Linux 内核负载。首次配置迁移把旧日志容量 128 KiB 改为 2048 KiB、旧控制台等级 8 改为 4；其他自定义值保留。迁移标记随配置备份保存，后续用户改值不会再被升级覆写。控制台等级不减少内核 ring 中的消息。
- **logd**：修复日志 ID 回绕时历史记录遗漏，并使全量读取预算适配配置的 ring 容量，保持慢读者和总积压上限。
- **dnsmasq**：发行 ELF 首次包含 F23 监听恢复修复，部分协议监听建立失败后会补建，正常 socket 保持不变。F25 为慢租约脚本增加有界背压：积压满时暂时拒绝新租约分配，保留续租、DNS 和已接纳的回调事件；脚本恢复后继续投递。未修改脚本超时约定，也不静默丢弃事件。两项一起重新完成 PGO 插桩、11 场景/50 profiles 训练和冻结。
- **netifd / platform**：reload 后更新现有网桥的 IGMP snooping 等属性；修复跨 vif 的 VLAN/STA 编号、SET_DATA 非字符串值及共享 VLAN 的 ifname/入桥；PD 长度限定为 1..64；GSTRINGS 按内核实际特征数校验缓冲区。
- **fw4 / UCI / odhcpd**：fw4 无法打开或获取锁时退出 1，不执行 nft；UCI 超大 reorder 数值按 C strtoul 的饱和规则处理；odhcpd 拒绝无法表示或发送的超长 DNS 选项/UDP 回复。
- **ubus**：blobmsg 转换最多接受 64 层 TABLE/ARRAY，超限正常报错，不 abort。C 原版对深输入也会崩溃，这项上限是明确加固。
- **procd**：对齐实例字段类型策略和 instance.update 事件；保留负 trigger timeout 的有符号语义、采用 watchdog 驱动实际接受的 timeout；加载并缓存 hotplug include，保留循环和 return 边界。
- **rpcd**：拒绝损坏的会话身份，避免恢复时间溢出；显式非法 UTF-8 SID 不再降为本地 root 请求；拒绝非零 base64 padding bits；LuCI 空 name 与未过滤一致；UCI 保存/提交错误不再被清理吞掉，失败 apply 停止并保留已有回滚快照与计时器。

部分边界也存在于 C 原版：永久慢 helper 的积压、深嵌套崩溃、过长 DHCPv6 回复及 UCI I/O 错误吞掉。修复选择资源上界和明确失败，不以重现原缺陷为兼容目标。`rollback=false` 仍不承诺事务性或自动回滚。

## 验证与实际部署

- Oracle 最终组合 **1717 项通过，0 失败**；10 个条件性 ignored 未计为通过。canonical SDK 的 21 条实际 daemon 回归命令通过。
- 新 dnsmasq ELF 完成 **44 类/67 项行为资格**，F23/F25 各四轮、资源受限回归及 40 次启动检查通过；冻结重建 ELF/APK 逐字节一致，零编译及 PGO missing/mismatch 警告。新 ELF SHA256 为 `2a22f6327d81e25c8bf9e891d21842e5ef0d33ec074e5004506388f3b616e2a2`。
- 同一构建提交的两轮完整镜像、5 个 APK、11 个实际 ELF、FIT/DTB/rootfs 和最终 manifest 全部逐字节一致。精确镜像的启动、所有权、APK 重装、守卫、PID1 交接、回滚包及日志迁移 **8/8 组**资格通过。
- 2026-10-20 保配置刷入后，600 秒观察窗 **31/31 次**客户端健康采样通过，覆盖 Wi-Fi、DHCP、DNS、IPv4/IPv6 HTTPS、LuCI、接口与 watchdog。无额外重启或回滚；观察已结束，临时回滚守卫和部署文件已正常撤除。

本次启动的串口相邻消息空档由 776.928 ms 降至 1.124 ms，DSA setup 由 3.352598 s 提前到 1.303311 s，MT7531 超时消失。但 WAN 链路由 15.648688 s 变为 21.513096 s，本次反而更晚；首刷 overlay 初始化路径不同，不能据此宣称完整启动提速。

末次 logread 仍保留初次 653 条开机记录及全部 267 条内核消息；logd RSS 为 780 KiB，HWM 1156 KiB。启动时 dnsmasq 自报丢失 3 条日志，观察期间另有 cron 校时跨度提示；没有新增 kern/daemon/user 告警或 overflow。这是一次 sysupgrade 启动和十分钟验收，**未做物理断电复验、连续 24 小时留存或长期稳定性验证**。
