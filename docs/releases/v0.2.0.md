# v0.2.0：新增 dnsmasq · OpenWrt 25.12.5

uci 沿用与本版相同程序的既有构建机测量。早期 dnsmasq 性能报告测的是另一候选，不能作为本版数据；两段 600 秒日常资源观察的流量、缓存和探测量不同，也不能作为同条件性能对比。其余未取得本版同条件数据的组件均记为“未测”。

本版完成保留配置刷写、正常重启及用户断电恢复。Mac 的 UDP DNS 检查在刷前 C、刷后 Rust 均出现超时，Rust 自动健康脚本只完成首组，不能记作完整健康窗口通过；路由器 DNS、客户端 TCP DNS、DHCP、双栈访问、LuCI 及用户 Wi-Fi 使用验收结果保留在[部署报告](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/DEPLOYMENT_V0_2_0_20261014.md)。
