# v0.3.1：可靠性修复 · OpenWrt 25.12.5

本版修复 v0.3.0 独立可靠性审查发现的问题，继续提供 11 个 Rust 组件，不含性能优化，也没有做性能测量。dnsmasq 与 v0.3.0 是同一个程序文件。

这些问题大多要先出现一次局部故障才会触发，例如启动时某个依赖暂时不可用、存储写满、端口被占用或脚本卡住，日常使用中没有观察到。修复的重点是让进程在故障解除后自动恢复，并给几处没有上限的队列和内存加上上限。每项修复都在隔离环境中先复现原版失败、再验证修复后通过；“C 原版也有”表示 OpenWrt 原实现存在同样问题。

**procd**

- 开机时向 ubus 注册 service、container、system 等对象如果失败，PID 1 会直接退出，系统起不来（C 原版不会退出）。现在注册失败会进入和运行期断线相同的重连流程，注册完成后才继续启动。
- 开机时 ubusd 第一次没能启动，之后不会再重试，系统停在启动中、不起网（C 原版会重试）。现在每秒重试一次，等待期间继续喂看门狗。
- inittab 里 respawn 命令为空时，记录错误日志会越界访问，导致 PID 1 崩溃。现在安全处理空命令。
- 按键按下的处理还没结束就松开时，松开事件可能错过取消定时器，误触发长按超时动作。现在处理开始时就取消对应定时器。

**ubusd 与 ubus 库**

- 读取很慢的本地客户端持续发送查询时，挂起的命令队列没有上限，会不断占用总线进程内存（C 原版也有）。现在每个客户端最多挂起 64 条命令和两倍最大消息长度，超出时断开该客户端。
- 同步请求超时后迟到的回复会被放进待处理队列，不会被清理。现在直接丢弃已过期请求的回复。

**netifd**

- 从内核读取地址、路由等列表时，如果读取过程中数据被修改，或列表以错误结束，原实现仍把不完整的结果当作完整（C 原版也有）。现在读完整个序列后报错，保留原有状态并重试。odhcpd 共用这部分代码。
- 协议脚本暂时无法执行时，接口一直停在“启动中”，脚本恢复后也不会起网。现在执行失败按脚本结束处理，之后可以重试。
- 依赖其他接口的协议（例如隧道），在下层接口晚到或反复断开恢复时不会跟着恢复或拆除。现在下层接口的状态变化会通知依赖它的接口。
- reload 时从网桥配置里删掉的端口，内核网桥中仍然保留；删掉最后一个端口时地址也没有撤掉。现在 reload 时会把这些端口从网桥移除。

**odhcpd**

- 启动时 RA 或 DHCPv6 套接字建立失败（例如端口暂时被占用），之后不会重试；进程仍在运行，所以 procd 不会重启它，但 DHCPv6 一直不回复（C 原版也有）。现在每秒重试缺失的套接字，正常的套接字保持不变。
- 租约触发脚本卡住时，之后每次租约变化都会再启动一个，进程数量没有上限。现在同一时间最多运行一个，期间的变化合并为一次后续调用；运行超过 35 秒会结束它的进程组。
- 前缀剩余寿命短于最小 RA 间隔时，无符号运算会算出过长的 RA 间隔，客户端可能来不及刷新地址。现在按前缀寿命限制间隔。

**rpcd**

- LuCI 应用配置前保存回滚快照时，如果空间不足导致快照不完整，仍会继续应用；到时回滚会用残缺快照覆盖原配置（C 原版也有）。现在先完整保存整批快照，任何一份失败就拒绝应用，不改动配置。
- 回滚写回失败时（例如只读或空间不足）快照仍被删除，配置没有恢复，也无法再试。现在保留快照、每秒重试直到成功；回滚进行中拒绝确认或取消，恢复时保留文件原属主，悬空的符号链接按其目标恢复。
- 另一个已登录会话只要有调用 `uci.apply` 的权限，即使没有对应配置的写权限，也能删掉别人待确认的回滚快照，让回滚失效（C 原版也有）。现在只有发起这次应用的会话能取消。
- 读取大文件计算 MD5 时会把整个文件读进内存，内存受限时进程会崩溃（C 原版正常）。现在按 8 KiB 分块计算。
- 修改不存在账户的密码时，提前返回而没有回收 `passwd` 子进程，每次请求留下一个僵尸进程。现在关闭输入后等待子进程结束。
- 本地软件包数据库出现异常短行时会越界崩溃。现在容忍截断的字段。

**uci**

- `uci commit` 会先清掉已保存的修改；如果随后写入新配置失败，配置没变，修改却丢了。现在新配置成功替换后才清除修改；清除这一步失败时恢复旧配置，避免重试时重复应用同一修改。

**reload_config**

- 系统日志队列满时，写日志会无限阻塞并一直持有配置锁，超时和 SIGTERM 都无法让它退出。现在日志套接字改为非阻塞。

**uhttpd**

- 请求头只限制单行长度，不限制总量，大量短请求头会让内存持续增长（C 原版也没有总量限制）。现在请求头总计不超过 64 KiB、最多 512 个字段，超出时返回 413 并关闭连接。

**行为变化**：uhttpd 对超大请求头返回 413；ubusd 会断开积压过多的客户端；odhcpd 的租约触发脚本运行超过 35 秒会被结束；rpcd 在快照不完整、回滚进行中或非发起会话取消时拒绝请求。

**未包含与已知限制**：dnsmasq 的修复（一种协议监听建立失败后不再补建）需要重新训练 PGO，留待以后的版本。用 apk 卸载本项目的软件包会同时删除 C 恢复备份和恢复工具，请勿把卸载当作回滚。dnsmasq 的租约脚本长期卡住时，待处理事件仍会持续累积，本版没有修改。

已完成保配置刷写和一次物理断电重启，两次启动后客户端都连续健康约 3 分钟，配置与刷写前一致，自动回滚守卫已解除。这是短时验收，不代表长期运行验证。详见[部署记录](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/DEPLOYMENT_V0_3_1_20261019.md)和[独立审查报告](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/V030_INDEPENDENT_REVIEW.md)。
