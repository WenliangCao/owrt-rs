# v0.3.4-r1 · 发版说明草稿

**暂不放行，未发布、未刷机。** 正式CI固件已经构建完成，但本轮严格的“最终候选相对线上无不重叠退步”门槛未通过。

以v0.3.3为基础升级Rust 1.100.0（LLVM 23.1.5）及16份锁定依赖。最终产品提交为 `1f9de983757880c14133998a5befcfdf1d4fafe5`。保留OpenWrt内核、驱动、执行面及原版恢复文件。

本次改动：

- HTTP请求体和CGI在中断/暂时不可读写时保留状态；停放TLS连接不因空readiness误关。
- DNS修复启动日志、名称与缓存判断、non-QUERY策略、relay出接口、hostsdir刷新；补齐配置CNAME接入缓存和DHCP relay hostname处理。
- netifd修复reload自启动、协议IP过期、配置类型与生命周期、外桥保护、offlink恢复及IPv6前缀class/路由归属；无线非有限值teardown不再abort，按ucode编码，删除排队radio后仍推进。
- odhcpd保留回复队列容量，并在混合前缀输入下返回与C相同的3个PD前缀（旧Rust仅2个）；logd最大记录回绕不再abort。
- 唯一性能改动是rpcd iwinfo查询去重。fw4、uci、procd等另保留兼容合同测试，不将测试本身计为缺陷修复。

**实际收益和代价。** 两张无线接口的iwinfo P50降低35.50%和40.03%，从约9.36/11.33ms降至6.03/6.79ms。DNS低速、饱和及6个DHCPv4客户端三组均无不重叠退步。11个ELF合计10,961,697字节，比线上少35,440字节。
