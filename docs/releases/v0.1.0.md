# v0.1.0：接管 9 组件 · OpenWrt 25.12.5

2026-09-29 发布。首个集成固件，将 procd、ubusd、netifd、rpcd、uci、reload_config、logd、uhttpd、fw4 九个 Rust 组件安装到系统标准路径，统一软件包管理，取代此前的组件绑定挂载。dnsmasq、odhcpd 仍使用原版。保留配置刷写、连续客户端健康检查及一次用户断电恢复验收通过。
