# v0.1.1：修复断管道与 IPv6 前缀到期 · OpenWrt 25.12.5

2026-10-09 发布。继续交付九组件 Rust 固件，修复 fw4、uci 及其他一次性诊断命令遇到断管道时的异常退出；netifd 补齐 IPv6 offlink 不可达路由、PD 下游源策略规则，以及没有新协议通知时的 PD 自然到期清理。dnsmasq、odhcpd 仍使用原版。

表中“C 原版”指 OpenWrt 原实现；fw4 原版为 shell/ucode。

上述基准在同一 aarch64 Linux 构建机的隔离环境中完成，每侧四轮，覆盖 15 种负载；它不是路由器性能数据，也没有测量 v0.1.0→v0.1.1 的性能变化。14 项耗时低于 C，netifd 无变化 reload 高 23.5%，保留为限制。未测项不沿用其他程序版本的成绩。

本版完成保留配置刷写与 Wi-Fi、WAN、LuCI、配置保留快速验收；未执行连续三分钟健康窗口或断电测试。LAN down/up 保留桥设备的既有差异未在本版修改。[修复与验收记录](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/HEALTH_20261008_FOLLOWUP.md)；[部署记录](https://github.com/WenliangCao/owrt-control-plane-rs/blob/main/docs/reviews/DEPLOYMENT_V0_1_1_20261009_RESULT.md)。
