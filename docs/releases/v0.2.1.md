# v0.2.1：优化 dnsmasq · OpenWrt 25.12.5

本版优化 dnsmasq：增加普通缓存命中快路径、静态 UDP 接收和同名 A/AAAA 缓存提示，使用固定 PGO 输入。继续提供 procd、ubusd、netifd、rpcd、uci、reload_config、logd、uhttpd、fw4、dnsmasq 共 10 个 Rust 组件，其余 9 个组件未改动。

同名 A/AAAA 命中的 J→K 九对比较中，单次查询 CPU 中位数由 123.08 降至 83.12 µs，p50 降低 22.65%。这是两个 Rust 候选之间的比较，不是 C 对照。原完整矩阵未见可辨退化；混合负载 CPU 配对中位数增加 4.21 µs、五对均同向变慢的趋势保留。AD/CD 和 EDNS 继续走通用路径。
